# Bundled fonts

The font assets are grouped by collection in `Inter/`, `Noto/`, and `Onest/`.
Each collection retains its font files and license notice.

## Embedded Inter faces

Inter 4.1, version `4.001;git-9221beed3`, from the official
[Inter release](https://github.com/rsms/inter/releases/tag/v4.1).

`Inter/Inter-Bold.ttf`, `Inter/Inter-Italic.ttf`, and
`Inter/Inter-BoldItalic.ttf` are unmodified static faces from `extras/ttf/`
in `Inter-4.1.zip` (SHA-256
`9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`).
They complement the existing unchanged `Inter/InterVariable.ttf` Regular bootstrap.
The collection also retains `Inter/InterVariable-Italic.ttf`.
All Inter faces are covered by [SIL Open Font License 1.1](Inter/Inter-LICENSE.txt).
