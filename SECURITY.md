# Security policy

Halcyon is an experimental beta. Security reports concerning the current
official source release are welcome. There is no guaranteed response time,
fix deadline, or maintenance period for older beta versions.

## Reporting a vulnerability

Use the repository's
[private vulnerability reporting form](https://github.com/halcyon-framework/halcyon/security/advisories)
on GitHub, where available.

Please include the affected version or source revision, platform, affected
component, security impact, and steps to reproduce the issue. Remove
credentials, personal data, and unrelated sensitive material from reports
and attachments.

If private reporting is unavailable, open a GitHub Issue requesting a
private reporting channel without including vulnerability details or
sensitive reproduction material.

Please coordinate disclosure with the maintainer rather than posting
sensitive details in a public Issue. Ordinary bugs and technical questions
belong in the public Issues channel.

Reporting a vulnerability does not establish a support contract, a bounty
entitlement, or a commitment to a particular resolution or release date.
