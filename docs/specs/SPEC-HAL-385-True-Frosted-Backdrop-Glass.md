# SPEC-HAL-385: True Frosted Backdrop Glass

**Status:** ADOPTED / BINDING for the first current same-surface Frosted Glass profile in section 8 and its coordinated owner amendments. Sections 1-7 retain intent where consistent with section 8. Implementation and JC optical acceptance are not implied.
**Date:** 2026-11-13.
**Owner:** Halcyon compositor, renderer and HAL-012 appearance resolution.
**Confirmed JC decision:** Real Frosted Glass with backdrop blur is distinct from Smoked Glass without backdrop blur.
**Governing owners:** HAL-002/002A, HAL-012, HAL-024, HAL-085A, HAL-354, HAL-359, HAL-084 and HAL-295A. Retired R-007/R-008 provide no current authority.
**Related candidates:** HAL-386 Smoked Glass; HAL-387 Surface Micrograin. Neither is an implicit fallback.
**First admitted observable scenario:** A native floating-looking panel composed within one qualified Halcyon base SurfaceId blurs moving lower-Z content on that same surface while preserving its sharp foreground text and controls. Reading an independent overlay/modal SurfaceId, another OS window or a swapchain is not admitted by this initial contract.

## 1. Problem, purpose, scope

A translucent rectangle, dark gradient or frozen screenshot cannot reproduce real frosted glass. This contract describes a backdrop-dependent material whose scattering acts on the *actual current background* at the lawful surface position. It changes presentation, never hit geometry, focus, input, accessibility geometry, layout or product data.

## 2. Optical contract

**INV-385-001 CURRENT BACKDROP:** With positive scattering the glass reads a qualified current composition of lower-order background content. It never samples its own output or its foreground descendants. A moving background changes the result in the next legitimately presented frame, not via an independent animation clock.

**INV-385-002 SCATTERING:** The authored Gaussian sigma is finite in 0..=24 logical pixels; sigma zero is an unblurred reference. The renderer derives physical support R=ceil(3*sigma*actual_target_DPR) pixels using the current positive finite DPR. Separable nonnegative Gaussian weights are normalized across the actually available kernel at each source boundary. At sigma=24, support is R=72 at 1x and R=144 at 2x. No cropped kernel, unqualified approximation or silent sigma/radius clamp is an admitted replacement.

**INV-385-003 EXACT TRANSMISSION AND COMPOSITION:** Let B be the actual lower-order prefix pixel on a renderer-owned *nonswapchain* intermediate in linear-premultiplied RGBA. F=Gaussian(B) with F=B for sigma=0. The tint C is finite straight-linear RGBA and P=(C.rgb*C.a,C.a) its premultiplied value; independently authored transmission t is finite in [0,1]. Define the replacement glass result G=t*F+(1-t)*P for all four channels. Let m in [0,1] be actual rounded own-SDF coverage times the lawful inherited clip coverage, each applied once. The updated prefix is O=(1-m)*B+m*G, also premultiplied. **O is a replacement, not G OVER an already drawn B**: the original prefix must appear exactly once, including translucent edges. Foreground text/icons/controls are rendered after O and remain sharp. An opaque tint may conceal valid blur and cannot alone prove backdrop filtering. Transmission is never inferred from alpha or product semantics.

**INV-385-004 INDEPENDENCE:** Micrograin HAL-387, reflective rim HAL-389, local ambient halo HAL-388 and emitted contour HAL-358 remain independent. No implicit grain, noise, rim, bloom or glow follows from selecting Frosted Glass.

## 3. Source authority and ordering

**INV-385-005 LEGAL RENDERGRAPH SOURCE:** The first execution contract is a closed, strictly ordered prefix of one SurfaceId. Existing HAL-359 strict different-Z order and immutable compositor surface order govern. HAL-084 Build declares nodes for (1) rendering actual lower-Z content into a renderer-owned sampled-capable nonswapchain prefix target; (2) finishing its write before reading a snapshot B; (3) the bounded horizontal/vertical Gaussian work using separately writable intermediate attachment(s); (4) computing the replacement O of INV-385-003 into a separate output target with B and F only as read-only inputs; (5) continuing the higher-Z scene and finally presenting to the swapchain *sink*. HAL-084 Compile validates acyclic dependencies, target formats, budgets and ownership; Execute runs only declared nodes. Every renderer-owned pass is represented in the graph under adopted HAL-084 INV-RG-009/010/011 and HAL-295A. Same live view read/write, ad hoc GPU encoder, independent widget resource and previous-frame screenshot are forbidden. Multiple frost operations require successive acyclic current-prefix epochs, not recursion.

**INV-385-006 CROSS-SURFACE REFUSAL:** Another compositor SurfaceId, independent overlay/modal surface, other OS window or previously presented swapchain is not a supported backdrop source. Visual overlap cannot authorize a cross-surface read. A separately adopted compositor source/lifetime extension would be required; retired R-007/R-008 and inactive HAL-363/364 do not provide it. If the prefix cannot be built faithfully, the request is typed-unavailable, never visually substituted.

## 4. Coordinates, color, resource bounds

**INV-385-007 BOUNDED FILTER:** R=ceil(3*sigma*DPR) is the authoritative physical kernel support; the initial admissible physical limit is R<=192 with a separately validated finite per-target region/attachment memory budget. Thus sigma=24 at 2x has R=144 and MUST pass the radius gate. A larger physical support, out-of-budget region or invalid scale fails explicitly; never clip the kernel, reduce sigma, enlarge hit/layout bounds or sample beyond the owned source. Fetch from the legal current-prefix region and renormalize weights at legal source boundaries; inherited visual clipping is applied to final m, not mistakenly to the source's frequency content.

**INV-385-008 PREMULTIPLIED LINEAR LAW:** B, F, P, G and O are bounded finite linear-premultiplied RGBA, componentwise 0<=RGB<=A<=1. Gaussian filtering and convex combinations preserve these bounds. The renderer applies the precise four-channel replacement O of INV-385-003; it must not additionally OVER the already-composed B, create zero-alpha colored fringes, apply a second sRGB transfer or multiply alpha twice. Own rounded AA and inherited clipping each appear once in m at actual physical DPR.

**INV-385-009 RETAINED DEPENDENCIES:** Actual source content/revision, source clip/scroll, destination geometry, sigma, tint, DPR/target and appearance generation are dependencies. Equal stable inputs may reuse valid retained output. Source change invalidates dependent glass even if its own style stays identical. Retired snapshots must never be reused after target/source loss.

**INV-385-010 RESOURCE CUSTODY:** Renderer-owned temporary attachments require exact resource, lifetime and target budgets. Insufficient allocation or missing legal source must be reported distinctly. This document authorizes no new offscreen producer, perpetual cache, per-widget Device/Queue or generic effects graph.

**FORBID-385-003:** Do not grant a widget framebuffer authority, expand layout or hit bounds, create an independent frame scheduler, global mutable state, unbounded kernel or hidden runtime activation.

### 8.4 Exact pixels, finite kernel and region sizes

Let W,H be actual physical target dimensions, D its DPR. Own SDF and mask use the same four-corner distance and derivative-AA law as HAL-386; only raster bounds expand by two physical pixels. Let V be the outward-integer-rounded own rect plus that AA margin, intersected with the existing physical rectangular scissor and target [0,W)x[0,H). V is a half-open integer pixel rectangle. If empty, no frost GPU work is needed. Rounded ancestor coverage is evaluated in the replacement, not approximated by V. Require finite nonnegative renderer clip-AA input and use max(renderer_clip_aa,0.5/D) for that captured mask, so its smoothstep interval is nonzero; do not change the old pipelines' AA setting.

For sigma>0, compute sigma_p=f64(sigma_logical)*f64(D), R=ceil(3*sigma_p), R<=192. Weights are w[0]=1 and w[k]=f32(exp(-0.5*(k/sigma_p)^2)) for k=1..R, computed with f64 intermediates; remaining slots are zero. Sigma zero has R=0 and identity filtering. Every actual discrete convolution divides by the sum of weights for available source taps; no edge-clamp repetition, downsampling or radius shortening. At sigma24/DPR2, R=144. Underflow of a negligible positive weight to zero is ordinary f32 representation, not a different kernel.

S=expand(V,R) intersect target. Capture precisely S from the real current prefix into snapshot B. Horizontal output Hx covers S, vertical output F covers V. At a horizontal output pixel, sum source pixels at integer x offsets within S/target with their symmetric weights and normalize available taps. Only Hx columns inside V are consumed vertically; those columns have their entire admitted horizontal support. Vertical output at a pixel of V sums Hx at integer y offsets and normalizes available taps. Because S includes R padding, an artificial ROI boundary never removes a tap needed by V. Both filters act on all four linear-premultiplied channels. Use integer textureLoad and no filtering sampler; sRGB texture decoding/encoding belongs to the format once, never a manual extra transfer. Hx and F use Rgba16Float with proved sampled/render-attachment usage, without an optional filtering feature.

### 8.5 Real graph sequence, no last-writer cycle

Only a surface with effective frost work gets a renderer-owned full-target accumulation texture A. All ordinary commands for that target are still encoded with their existing pipelines/Globals and exact physical coordinates. Other surfaces retain the old graph and no frost allocation.

Assemble CPU-only per-target graph topology from the completed immutable draw schedule at the renderer's EXISTING topology-build seam, after normal command admission and before frost physical allocation. This is topology assembly, not another UI/frame phase. The order is:
1. Clear A with the admitted current clear and encode the first normal command segment.
2. At each frost marker, finish that render pass; copy S from A to a distinct snapshot texture B through a declared graph copy node.
3. Run horizontal blur B->Hx and vertical blur Hx->F through declared graph nodes.
4. Replace the pixels in V of A using read-only B/F and the equation in 8.6, with blending DISABLED; retain A outside V through Load.
5. Resume the exact next normal segment using Load. Repeat for later markers, respecting the Main/Overlay boundary.
6. Render one terminal full-target transfer of A to the actual output view, with blending DISABLED and integer pixel correspondence. The swapchain is only this sink and is never copied or sampled as source.

The physical A is reused sequentially, but each producing segment/replacement receives a DISTINCT logical AttachmentHandle version. Each logical version has exactly one writer; readers depend on that version, and each overwrite depends on completion of preceding readers. Bind those version handles to the same physical A only after the pure graph validator proves no overlapping sampled/copy read and overwrite. An ordered attachment Load may consume the prior version at the start of its producing render pass; it is not an overlapping texture sample. The current RenderGraphBuilder final-writer map must NOT be fed one multiply-written source handle, which would create wrong dependencies or cycles. Attachment Load preserves prior destination contents; it is not shader feedback. No pass samples the texture it is currently writing. B/Hx/F each have distinct handles. Explicit dependencies preserve the complete sequence and the last-reader-before-overwrite condition. Do not weaken cycle detection.

Pass names remain unique finite static names (bounded arrays for occurrences 0..15 and segments 0..17 (the extra split is the Main/Overlay boundary)), not leaked dynamic strings or duplicate names. Pass executors receive only their declared handles, immutable ranges/parameters and existing constrained PassContext resources; no Device/Queue/Surface/pool, no allocation and no hidden encoder submission. The graph's frozen resource bindings may expose the captured source/destination texture objects for the copy executor, but not arbitrary renderer resources or widget-selected handles.

The current output command schedule is the source of truth. Missing or withdrawn required lower-prefix content cannot be called a complete source: existing required-text refusal prevents output, and a lower-prefix image removed by normal image admission makes the participating frost surface IncompletePrefix instead of silently blurring an incomplete background. Preserve old no-frost admission outcomes. No invented historical frame restores an incomplete current prefix.

### 8.6 Replacement and optional tint-only grain
