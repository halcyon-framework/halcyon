## 1. User-visible capability

A source-qualified selected 3D object receives a crisp, stable external silhouette outline. The independently selected first profile is static, visible-only, 2.0 **physical** pixels wide, display-linear RGB `(0.24,0.62,0.84)`, opacity1 on the stroke with actual subpixel edge antialiasing. Width does not scale with DPR. Halo blur, flash and pulse are excluded from this first delivery. Real occlusion and camera orbit affect the boundary; hidden geometry must not show through an occluder. Selecting a different object or replacing the source removes the stale effect immediately. Original PBR pixels inside and outside the qualified outer stroke remain unchanged. No selection uses the original canonical path with bit-identical output/behavior and no mandatory extra Image.
